# Config file for 💤 LazyVim

This is an evolving config for my NeoVim setup.
It is constantly changing as I dial it in.

Most of my development is for .NET, Typescript and some Go.

For debugging I originaly rolled my own DAP setup but it had a few issues.
I eventualy found [easy-dotnet](https://github.com/GustavEikaas/easy-dotnet.nvim)
and it has been pretty great so far. Follow the documentation for installation.

This is config started from the template for [LazyVim](https://github.com/LazyVim/LazyVim).
Here is the [documentation](https://lazyvim.github.io/installation).
